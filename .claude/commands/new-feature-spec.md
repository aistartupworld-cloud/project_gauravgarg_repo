argument-hint: <feature-name>
---
Create `specs/$ARGUMENTS_spec.md` using this outline, then add it to `specs/app_spec.md` and `AGENTS.md`:

```
# <Feature> spec
Status: Draft · Owner agent: <agent>
## Purpose
## Actors and permissions
## Data
## Rules
## API
## UI
## Acceptance Criteria
### AC-NN <title>
- Given … When … Then …
## Out of scope
```
Reuse the brief's AC ids where they apply. Ask before inventing a new AC id.
